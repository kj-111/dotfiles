# Alacritty installeren
#
# Zit buiten Homebrew sinds 1-9-2026: de cask is disabled omdat de officiele build
# adhoc gesigneerd is (geen TeamIdentifier) en dus niet door Gatekeeper komt. Dat is
# een eis van Homebrew, geen probleem in Alacritty.
#
#   1. Alacritty-vX.Y.Z.dmg van de releasepagina hierboven
#   2. Alacritty.app naar /Applications slepen
#   3. xattr -dr com.apple.quarantine /Applications/Alacritty.app
#   4. de symlinks die de cask legde, nu in eigen ruimte:
#
#      A=/Applications/Alacritty.app/Contents
#      mkdir -p ~/.terminfo/61 ~/.local/bin ~/.local/share/man/man1 ~/.local/share/man/man5
#      ln -sf $A/Resources/61/alacritty        ~/.terminfo/61/alacritty
#      ln -sf $A/Resources/61/alacritty-direct ~/.terminfo/61/alacritty-direct
#      ln -sf $A/MacOS/alacritty               ~/.local/bin/alacritty
#      ln -sf $A/Resources/alacritty.1.gz      ~/.local/share/man/man1/alacritty.1.gz
#      ln -sf $A/Resources/alacritty-msg.1.gz  ~/.local/share/man/man1/alacritty-msg.1.gz
#      ln -sf $A/Resources/alacritty.5.gz      ~/.local/share/man/man5/alacritty.5.gz
#      ln -sf $A/Resources/alacritty-bindings.5.gz ~/.local/share/man/man5/alacritty-bindings.5.gz
#
# Alleen de terminfo-link moet echt: alacritty.toml zet TERM="alacritty" en macOS kent
# die entry niet (ncurses 6.0 uit 2015, geen alacritty in /usr/share/terminfo/61/).
# Zonder hem geven clear en tput "unknown terminal"; nvim en less overleven het wel.
# MANPATH hoeft niet gezet: macOS leidt de manpath af uit PATH, en ~/.local/bin staat
# er al in, dus ~/.local/share/man komt vanzelf mee.
#
# Bijwerken is stap 1 t/m 3 opnieuw. De symlinks wijzen naar een vast pad in de bundel
# en blijven staan.
