# JetBrains-shortcuts voor Windows (examen)

Voor PyCharm, WebStorm en IntelliJ met de Windows-keymap. Setup:
`examen-setup.md`. Gebruik op de Mac de rechter Option als `Alt`; de linker is
via Hyperkey gemapt.

## Basis

- `Shift Shift` — Search Everywhere · `Ctrl+Shift+A` — Find Action
- `Shift+F10` — run · `Ctrl+Shift+F10` — run huidig bestand
- `Shift+F9` — debug · `Esc` — terug naar de editor

## Navigeren en bewerken

- `Ctrl+←/→` — woord · `Home/End` — regel · `Ctrl+Home/End` — bestand
- `Page Up/Down` — pagina · `Alt+↑/↓` — vorige/volgende methode
- `Ctrl+[/]` — begin/einde codeblok · houd `Shift` erbij om te selecteren
- `Ctrl+/` — comment · `Ctrl+D` — dupliceren · `Alt+Shift+↑/↓` — verplaatsen
- `Ctrl+W` / `Ctrl+Shift+W` — selectie uitbreiden/verkleinen
- `Tab` / `Shift+Tab` — inspringen/uitspringen
- `Ctrl+Alt+L` — formatteren · `Ctrl+Alt+O` — imports opruimen
- `Ctrl+Z` / `Ctrl+Shift+Z` — undo/redo
- `Ctrl+Y` — regel verwijderen, niet redo
- `Ctrl+X` / `Ctrl+C` zonder selectie — hele regel knippen/kopiëren

## Codehulp

- `Ctrl+Space` — completion · nogmaals — ruimere completion
- `Ctrl+Shift+Space` — typegerichte completion
- `Ctrl+Alt+Space` — type completion met auto-import
- `Ctrl+P` — parameters · `Ctrl+Shift+P` — type van expressie
- `Ctrl+Shift+Enter` — statement afmaken
- `Ctrl+Q` — documentatie, ook in completion · nogmaals — vastpinnen
- `Ctrl+B` — definition · `Ctrl+Shift+I` — quick definition / completion-broncode
- `Ctrl+F1` — foutmelding · `Alt+Enter` — quick fix
- `F2` / `Shift+F2` — volgende/vorige fout

In de completion-lijst voegt `Enter` in en vervangt `Tab` het huidige woord.
`Shift+F1` opent externe documentatie; zonder internet gebruik je `Ctrl+Q`.

## Zoeken, refactoren en debuggen

- `Ctrl+F` / `Ctrl+R` — zoeken/vervangen · `Ctrl+G` — ga naar regel
- `Ctrl+E` — recente bestanden · `Shift+F6` — rename
- `Ctrl+F8` — breakpoint
- `F8` — step over · `F7` — step into · `Shift+F8` — step out
- `F9` — resume · `Alt+F8` — evaluate expression
- `Alt+F12` — terminal
